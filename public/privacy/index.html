Privacy Policy – Bolati Pustake

Effective date / Last updated: 29 September 2026

Bolati Pustake (“we”, “our”, or “us”) values the privacy of visitors, listeners, and anyone contacting us through our website or related channels. This Privacy Policy explains what information we may collect, how it is used, and how you can contact us regarding privacy-related requests.

This policy reflects the data and services currently present in the inspected codebase for this project. Based on the repository reviewed, the site does not currently implement a user account system, login flow, app purchase checkout, payment gateway integration, or Android app backend in this codebase. The information below therefore describes only the data processing that is actually visible in the project.

1. Information we collect

Depending on how you interact with Bolati Pustake, we may collect the following information:

Contact information
  • Name
  • Email address
  • Phone number
  • Message subject and content submitted through the contact form
Device and technical information
  • IP address
  • Browser type and version
  • Device information and operating system
  • Pages visited and timestamps
  • Referral or source information

We also use browser storage in the website to remember a language preference and maintain a local visitor counter. In the current codebase, this is stored in the browser using localStorage and is not a user account system.

2. How information is used

We use the information we collect for the following purposes:

  • To respond to user enquiries and messages submitted through the website contact form.
  • To improve the usability and accessibility of the website.
  • To understand website traffic and general usage patterns using standard hosting and traffic logs.
  • To remember user language preference in the browser for a better experience.

3. Contact form and message processing

The website includes a contact form that sends submitted data to the external automation endpoint: https://automation.mysamvedana.org/webhook/bolati-pustake-web .

This form collects and submits the user’s name, phone number, email address, subject, and message for handling by the team or workflow configured for the website. We do not see evidence in this codebase of a separate customer database, login system, or app-specific CRM for user records.

4. Audiobook purchases, payments, and user accounts

We have not identified any implemented audiobook purchase flow, user account creation flow, payment processing code, or checkout integration in the current project. There is no evidence in the repository of a payment gateway such as Stripe, Razorpay, PayPal, subscription billing, or stored card/UPI data management within this site.

If a future app or backend introduces purchases, subscriptions, or payment processing, the payment data will be handled by the dedicated payment provider and not stored directly on the Bolati Pustake website unless explicitly stated in a future update to this policy.

5. Third-party services

Based on the current project and source code reviewed, the following are the only third-party services clearly used by the site:

  • Website contact automation endpoint: https://automation.mysamvedana.org/webhook/bolati-pustake-web
  • Hosting and domain infrastructure: the website is served via the hosting provider for bolatipustake.in, which may record standard server logs and traffic information needed to operate the site.

The current codebase does not contain evidence of third-party analytics providers such as Google Analytics, Firebase, or similar tracking SDKs. We do not claim use of analytics or advertising tools unless they are implemented in a future version of the platform.

6. Data storage and security

We store limited information necessary to operate the website. This includes browser-local preferences and the contact form data submitted through the dedicated automation endpoint. The website uses HTTPS for secure browser communication.

We take reasonable steps to protect information using secure hosting practices, restricted access to operational tools, and standard website security measures. However, no method of transmission or electronic storage is completely risk-free, and we cannot guarantee absolute security.

7. Data retention

We retain information only as long as necessary for the purpose for which it was collected or as required by applicable law, contract, or operational need. Contact form submissions may be retained for business communication and support handling purposes. Browser localStorage values may remain on the device until the user clears them or the browser removes them.

8. Deletion of data / account removal requests

If you want to request deletion of your contact information or any privacy-related data held by us, please contact us via the contact details below. We will review the request and respond as reasonably as possible.

Since this project does not currently implement an account system or persistent user database in the inspected codebase, there is no automated self-service account deletion flow in the current website.

9. Children’s privacy

Our website and content are intended for general audiences. We do not knowingly collect personal information from children in a way that suggests direct marketing or profiling. If a parent or guardian becomes aware that a child has submitted personal information to us without permission, please contact us so we can take appropriate steps.

10. User rights and privacy requests

You may have rights regarding access, correction, deletion, or objection to certain processing, depending on your jurisdiction.

  • Request access to the personal data we hold about you.
  • Request correction of inaccurate information.
  • Request deletion of personal information when appropriate.
  • Ask questions about how we process your data.

Please contact us using the details below and include a clear description of your request.

11. Changes to this Privacy Policy

We may update this Privacy Policy from time to time to reflect changes in the website, services, legal requirements, or our operating practices. The “Last updated” date at the top will indicate when the policy was revised.
